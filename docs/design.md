# 界面风格

- 类型：工具
- 风格：黑白 · 简约（参考 Apple 官网与系统应用）
- 颜色：近黑主色 `#1d1d1f`，浅灰画布 `#f5f5f7`，白色卡片；次要文字 `#6e6e73` / `#86868b`；危险色 `#d70015` 只用于错误
- 主题：`frontend/src/styles/theme.css`；Konva 从同一套 CSS token 读取颜色
- 圆角：10 / 12 / 18 / 24px（徽标 / 输入框 / 卡片 / 面板）；按钮一律胶囊形；控件高度 32–40px；正文 14px，辅助文字不低于 11px
- 层级：靠留白、字重和极轻的阴影区分，不用彩色装饰；大标题 32–48px、字距收紧
- 布局：毛玻璃顶栏，分段式导航；编辑器使用画布、AI 对话、属性分区
- 手机：底部标签栏，编辑器通过分段控件切换画布和 AI 对话；390px 无页面横向溢出
- 动效：减速曲线 `--ease-out`，按压与弹出用回弹曲线 `--ease-spring`；页面区块依次上浮入场，卡片悬停轻微上浮，导航滑块跟随当前页，首页滚动揭示；一律尊重减少动态效果偏好
- 背景：首页各区、工作台空白处和登录页铺一层黑白粒子（`components/ParticleField.tsx`，漂移 + 近邻连线 + 鼠标推开）；编辑器不加，离屏或标签页隐藏时暂停
- 组件样式放在 `@layer components`，保证同一元素上的 Tailwind 工具类可以覆盖
